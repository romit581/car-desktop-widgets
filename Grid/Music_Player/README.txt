ROMIT MUSIC PLAYER — RAINMETER
================================

What it does
-------------
A compact music widget styled after the supplied reference:
- Album artwork
- Current track title
- Artist
- Progress bar
- Previous / Play-Pause / Next
- Current player label
- Automatic metadata updates through WebNowPlaying

Supported
---------
Browser Spotify: yes
SoundCloud: yes
Other WebNowPlaying-supported browser players: generally yes

Spotify Desktop
---------------
Spotify Desktop requires the WebNowPlaying Spicetify extension.
Install Spicetify + the WebNowPlaying extension from the Spicetify Marketplace.

INSTALLATION
------------
1. Install Rainmeter.
2. Install the WebNowPlaying Rainmeter adapter/plugin.
3. Install the WebNowPlaying browser extension for Chrome/Edge/Firefox.
4. Put the "Romits_Music_Player" folder into:
   Documents\Rainmeter\Skins\
5. In Rainmeter, Refresh all.
6. Load:
   Romits_Music_Player\MusicPlayer.ini

If WebNowPlaying v2 does not work on your Windows build, use the current
WebNowPlaying-Rainmeter v3 alpha release, as newer Windows updates have
broken older plugin builds.

NOTES
-----
For browser Spotify/SoundCloud, the browser tab must be playing the media
and the WebNowPlaying extension must be installed/enabled.

The widget itself does not stream music. It controls the player that is
already playing.
