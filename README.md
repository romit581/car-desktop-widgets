## ⚡ About

**Racing HUD** is a custom Rainmeter desktop suite inspired by:

- 🏎️ Motorsport dashboards
- 🎮 Racing-game HUDs and menus
- 🖥️ Minimalist desktop interfaces
- 🧊 Glassmorphism / dark glass UI
- ⚫ Monochrome automotive photography
- 🔴 Red-accented performance interfaces

The goal was to create a desktop that feels like a **modern racing-game garage / telemetry interface**, while keeping the widgets minimal enough to remain practical for everyday use.

The design was built around a simple visual language:

**Black / White / Gray + Red**

Every widget follows the same typography, spacing, transparency, and circular HUD styling to make the entire desktop feel like one unified interface.

---

## 🖥️ Widgets Included

### 🕒 Clock & Date

A minimal racing-style clock displaying:

- Current time
- Current date
- Short motivational text

Designed to occupy the upper-left area of the desktop.

---

### 📁 Shortcut Panel

A vertical glass-style launcher for commonly used locations and applications.

Current shortcuts include:

- This PC
- Downloads
- Recycle Bin

The panel can be customized with additional shortcuts.

---

### 🎵 Music Player

A minimal music-control widget designed to fit the racing HUD aesthetic.

Includes:

- Album artwork
- Track information
- Previous / Play / Next controls
- Minimal progress indicator

---

### 📊 System Monitor

Circular performance indicators displaying:

- CPU usage
- GPU usage
- RAM usage

The meters use a red accent to maintain the visual language of the rest of the suite.

---

## 🎨 Design Inspiration

This Rainmeter desktop setup is inspired by Race Driver: GRID, particularly its distinctive racing HUD, menus, telemetry-style interface, and overall motorsport presentation.

The design takes visual cues from the game's:

🏁 Racing HUD and dashboard interfaces
⚙️ Minimal telemetry-inspired layouts
🟥 Red and monochrome accent colors
🖥️ Dark, high-contrast UI elements
🚗 Motorsport photography and racing aesthetics

Note: This is a fan-made desktop customization project inspired by Race Driver: GRID. It is not affiliated with or endorsed by Codemasters or Electronic Arts.
